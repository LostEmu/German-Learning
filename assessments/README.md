# Assessment Policy

This file sets out how work is assessed, what a pass is, and when a topic counts as mastered. The aim is **genuine proficiency**, so marking is strict and progress is never inflated.

---

## 1. Types of assessment

| Type | When | Content | Folder |
|---|---|---|---|
| **Guided exercises** | During every lesson | Scaffolded practice, getting gradually harder | `exercises/<level>/` |
| **Lesson test** (independent assessment) | End of every lesson | Free production of that lesson's material, with no notes | `lesson-tests/` |
| **Cumulative assessment** | Every 5 lessons | All material so far, weighted towards the last 5 lessons | `cumulative-tests/` |
| **Major exam** | Every 10 lessons | Separate sections: grammar, vocabulary, reading, writing (plus listening/speaking tasks where possible in text) | `cumulative-tests/` |
| **CEFR checkpoint** | End of each level | Modelled on Goethe-Zertifikat / telc formats for that level | `CEFR-assessments/` |

Sentence construction (translation, free writing, sentence building) is always part of an assessment. Multiple choice is used sparingly.

## 2. Pass marks

| Assessment | Pass mark | If not passed |
|---|---|---|
| Guided exercises | none (diagnostic only) | Errors are explained and logged; re-teaching if the same error repeats |
| Lesson test | **80%** | The weak points are re-taught and a short re-test is given before the next lesson |
| Cumulative assessment | **80% overall, no section below 70%** | Remedial lesson(s) are added to the curriculum |
| Major exam | **80% overall, no section below 70%** | Remedial lessons, then a re-sit of the failed sections |
| CEFR checkpoint | **80% overall, no section below 70%** | No move to the next level until it is passed |

> These pass marks are deliberately stricter than official exams (which typically pass at 60%). Official exams certify *minimum* competence; this programme aims for *secure* competence.

## 3. Mastery scale

Every grammar topic in `progress/progress-tracker.md` has one of these statuses:

| Status | Meaning |
|---|---|
| **Not started** | Not yet taught |
| **Introduced** | Taught; guided exercises attempted |
| **Practising** | Lesson test passed, but errors still appear in later work |
| **Secure** | Used correctly in free production in a later lesson or test |
| **Mastered** | Used correctly (≥ 90% accuracy) in free production on **at least two separate occasions**, at least one of them a cumulative test taken **≥ 1 week** after the lesson |

A topic can be **downgraded** if errors come back.

## 4. Writing rubric (used from the first free-writing task)

Each written answer is marked out of 10:

| Criterion | Points | What is assessed |
|---|---|---|
| Task fulfilment | 3 | All parts of the task covered; appropriate register (du/Sie) |
| Grammatical accuracy | 3 | Verb forms, word order, case, gender, agreement |
| Vocabulary | 2 | Range and correct use; correct articles and spelling (including capital letters on nouns) |
| Coherence | 2 | Logical order, natural connectors, idiomatic phrasing |

## 5. Error categories (used in `progress/mistakes-log.md`)

| Code | Category |
|---|---|
| `PRON` | Pronunciation / spelling–sound correspondence |
| `SPELL` | Spelling, capitalisation, umlauts |
| `VERB` | Verb conjugation or verb form |
| `WO` | Word order (verb position, etc.) |
| `CASE` | Case (nominative / accusative / dative / genitive) |
| `GEN` | Noun gender / article choice |
| `REG` | Register (du vs Sie, formal vs informal) |
| `VOC` | Wrong word / false friend / meaning |
| `PREP` | Preposition choice |
| `IDIOM` | Unnatural or non-idiomatic expression |
