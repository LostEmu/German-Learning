## 1. The verb-second rule (V2) *(Lesson 1)*

**In a German main clause, the conjugated verb is always the second element.**

An *element* is a unit of meaning, so it may be more than one word.

| Position 1 | Position 2: **verb** | Rest |
|---|---|---|
| Ich | **heiße** | Alex. |
| Mein Name | **ist** | Alex. |
| Ich | **komme** | aus Australien. |
| Ich | **studiere** | auch Physik. |

*Mein Name* = two words, one element → the verb is still in position 2.

## 2. W-questions *(Lesson 1)*

The question word occupies position 1, the verb stays in position 2, and the **subject moves to after the verb**.

| Position 1: W-word | Position 2: **verb** | Subject | Rest |
|---|---|---|---|
| Wie | **heißt** | du? | |
| Woher | **kommen** | Sie? | |
| Wo | **wohnst** | du? | |
| Wie | **geht** | es | dir / Ihnen? |

**Contrast with English:**
- English uses an auxiliary *do* ("Where **do** you live?"). German **never** does: *Wo wohnst du?*
- English can split *where … from*. German uses the single word **woher**.

| Question word | Meaning |
|---|---|
| wie | how (also used for names: *Wie heißt du?*) |
| wo | where (location) |
| woher | where … from (origin) |
