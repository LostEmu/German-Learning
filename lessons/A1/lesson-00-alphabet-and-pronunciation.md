---

## 1. Learning objectives

By the end of this lesson you should be able to:

1. Name the 26 letters plus Ä, Ö, Ü and ß, and spell words aloud (names, email addresses, street names).
2. Predict whether a stressed vowel is **long or short** from the spelling.
3. Pronounce the umlauts (ä, ö, ü) and the diphthongs (ei, ie, au, eu/äu) correctly.
4. Produce the consonant sounds that differ from English: **w, v, z, j, s, sch, sp/st, ch, r, ß**.
5. Apply **final devoicing** and put **word stress** in the right place.
6. Know the key spelling conventions: capitalised nouns, ß vs ss, and the Swiss "no ß" rule.

**Why this matters:** German spelling is far more regular than English (or French). Once you know about 30 rules you can pronounce almost any word you read, including words you have never seen. Getting the sounds right early prevents fossilised errors that are very hard to fix later.

## 2. The alphabet

German letter names. The sound guides use **Australian English** reference points, and French ones where they help.

> ⚠️ **Watch out, Australian English speakers:** German long **e** and long **o** are *pure* vowels. Your "ay" in *day* glides (roughly [dæɪ]) and your "oh" in *go* glides a lot (roughly [ɡəʉ]). German doesn't glide. The **French** vowels in *été* and *beau* are much closer.

**Classic spelling-aloud traps for English speakers:**
- **E** ("eh") vs **I** ("ee"): the English names are swapped.
- **A** ("ah") vs **R** ("air").
- **G** ("geh") vs **J** ("yot").
- **V** ("fow") vs **W** ("veh").
- Double letters: say *Doppel-* or *zwei*: "Mann" = *em – ah – Doppel-en*.

## 3. Vowels

### 3.1 Long vs. short: the most important pronunciation rule

Every German vowel exists in a **long** and a **short** version. Length changes meaning: *Staat* (state) vs. *Stadt* (city), *Miete* (rent) vs. *Mitte* (middle).

**The vowel is usually LONG when:**

| Rule | Examples |
|---|---|
| It is doubled: **aa, ee, oo** | Haar, See, Tee, Boot |
| It is followed by a **silent h** | Bahn, sehr, ihr, Uhr, wohnen |
| It is spelled **ie** | die, Sie, wie, vier |
| It is followed by **one** consonant | Name, Tag, gut, Kino |
| It ends a syllable | ja, du, so, wo |

**The vowel is usually SHORT when:**

| Rule | Examples |
|---|---|
| It is followed by a **double consonant** | Mann, Bett, Sonne, bitte, kommen |
| It is followed by **ck** (= double k) or **tz** (= double z) | Zucker, Platz, Katze |
| It is followed by **two or more consonants** (usually) | und, ist, Kind, Stadt |

**Exceptions** you'll meet early: many short function words have a short vowel before a single consonant: *in, an, mit, das, es, um, ob, bis, hat*.

### 3.2 The pure vowels

| Vowel | Long | Example | Short | Example | Unstressed |
|---|---|---|---|---|---|
| **a** | [aː] "ah" | Name, Tag | [a] like Australian *cup* | Mann, das | |
| **e** | [eː] French *é* | geht, See, Tee | [ɛ] like *bed* | Bett, essen | [ə] schwa, like *a* in *sofa*: bitt**e**, Nam**e**, dank**e** |
| **i** | [iː] "ee" (no glide) | ihr, Kino | [ɪ] like *bit* | ist, in, bitte | |
| **o** | [oː] French *eau* | so, Boot, wohnen | [ɔ] like Australian *hot* | Sonne, kommen | |
| **u** | [uː] French *ou* | gut, du, Schule | [ʊ] like *put* | und, Mutter | |

> **Australian-accent note on u:** Australian English pronounces the *oo* in *food* quite far forward in the mouth. German **u** is further back, with the lips strongly rounded and pushed forward, like French *ou*.

> **Unlike French:** final **-e is always pronounced** in German. *bitte* = BIT-tuh (2 syllables), *Name* = NAH-muh.

### 3.3 Umlauts

The two dots change the vowel's quality. They are not decoration: *schon* (already) ≠ *schön* (beautiful), *Mutter* (mother) ≠ *Mütter* (mothers).

| Umlaut | How to make it | Long | Short |
|---|---|---|---|
| **ä** | Like German *e*, slightly more open; long ä ≈ Australian *air* (no r) | Käse, spät [ɛː] | Männer, Äpfel [ɛ] |
| **ö** | Say German long *e* [eː], then **round your lips** as for "oh" without moving the tongue. French *deux* | schön, hören [øː] | können, zwölf [œ] (French *neuf*) |
| **ü** | Say "ee" [iː], then **round your lips** as for "oo" without moving the tongue. French *tu* | über, grün, **Zürich** [yː] | fünf, müssen [ʏ] |

**Typing umlauts:** if you have no umlaut keys, write **ae, oe, ue** (and **ss** for ß): *Zuerich, Koeln, Strasse*. This is standard in email addresses and URLs.

### 3.4 Diphthongs (two vowels gliding together)

| Spelling | IPA | Sound | Examples |
|---|---|---|---|
| **ei, ai** (rarely ey, ay) | [aɪ̯] | "eye" | mein, zwei, heißen, Mai, Bayern |
| **au** | [aʊ̯] | "ow" in *how* | Haus, auch, Frau, aus, Australien |
| **eu, äu** | [ɔʏ̯] | "oy" in *boy* | neu, heute, Deutsch, Europa, Häuser |
| **ie** | [iː] | "ee" (*not* a diphthong) | die, Sie, wie, vier, Bier |

**Mnemonic for ei vs. ie:** pronounce the **English name of the second letter**.
- e**i** → "I" → *eye* → *mein* = "mine"
- i**e** → "E" → *ee* → *Wien* (Vienna) = "veen"
- Minimal pair: **Wein** (wine) [vaɪ̯n] vs. **Wien** (Vienna) [viːn]

**Exception:** at the end of some foreign-derived words, *ie* is two separate sounds [i̯ə]: Famil**ie** [faˈmiːli̯ə], Austral**ie**n [aʊ̯sˈtraːli̯ən].

**French trap:** German *eu* is "oy", **not** French *eu*. *Deutsch* = "DOYtsh".

## 4. Consonants

Most consonants are as in English. These are the ones that differ:

| Spelling | Sound | Examples | Notes |
|---|---|---|---|
| **w** | [v] | wie, was, Wasser, wohnen | Never an English *w* |
| **v** | [f] | Vater, vier, viel, von | In many loanwords [v]: Vase, Video, Universität |
| **j** | [j] (English *y*) | ja, jung, Juni | Not French *j* |
| **z, tz** | [ts] | Zeit, zwei, **Zürich**, Platz | Never an English *z* |
| **s** + vowel | [z] | Sie, sehr, Sonne, Physik | Standard German in the north. In Switzerland, Austria and southern Germany, often [s] |
| **s** elsewhere | [s] | das, ist, Haus | |
| **ss, ß** | [s] | Wasser, heißen, Straße | See §6 for the ß/ss spelling rule |
| **sch** | [ʃ] ("sh") | Schule, schön, Tisch | |
| **sp-, st-** at the start of a word/stem | [ʃp], [ʃt] ("shp", "sht") | sprechen, Sport, Stadt, Student, ver**st**ehen | Elsewhere [sp]/[st]: ist, Fenster |
| **tsch** | [tʃ] ("ch" in *church*) | Deutsch, tschüss | |
| **ch** after **a, o, u, au** | [x] "ach-sound" | acht, Nacht, Buch, noch, auch | Like Scottish *loch*. Friction at the back of the mouth |
| **ch** everywhere else | [ç] "ich-sound" | ich, nicht, Milch, München, Mädchen, Mechanik | See below. Neither "k" nor "sh"! |
| **chs** | [ks] | sechs, wachsen | |
| **-ig** at the end of a word | [ɪç] | zwanzig, richtig, König | Southern Germany and Switzerland: [ɪk]. Before a vowel: [ɪɡ] (Könige) |
| **h** at the start of a syllable | [h] | Hallo, Haus | |
| **h** after a vowel | silent (marks a long vowel) | gehen, sehr, Uhr, wohnen | *gehen* = [ˈɡeːən]. Do **not** pronounce this h |
| **th** | [t] | Theorie, Mathematik | Never English *th* |
| **ph** | [f] | Physik, Philosophie | |
| **qu** | [kv] | Quelle, **Quantenmechanik** | "kv", not "kw" |
| **pf** | [pf] (both letters) | Apfel, Pferd, Kopf | Say *cu**p f**ull* quickly |
| **kn, gn, ps** at the start | both letters | Knie, Gnade, Psychologie | The first letter is *not* silent |
| **ng** | [ŋ] | lang, jung, Finger | As in *singer*, never *finger*: no g sound after it |
| **-tion** | [tsi̯oːn] | Information, Funktion | "tsee-OHN" |
| **dt** | [t] | Stadt | |

### 4.1 The ich-sound [ç]: how to produce it

This is the sound English speakers find hardest. Three routes in:
1. Say the English word **"huge"** slowly. For many speakers the *h* in *huge* already *is* [ç].
2. Whisper the *y* in **"yes"** forcefully, with no voice. The hiss you hear is [ç].
3. Say "ee", keep your tongue exactly there, and push air through hard.

Avoid both common substitutes: "ick" (that is Berlin dialect!) and "ish" (heard in some regions, but not standard).

### 4.2 The German R

| Position | Sound | Examples |
|---|---|---|
| Start of a syllable, after consonants | [ʁ]: a soft friction at the back of the throat (uvula), like **French r** | rot, Reise, Brot, drei, hören |
| After a long vowel at the end of a syllable | vocalised [ɐ̯]: becomes a vowel-like "uh" | der, mir, vier, Uhr, sehr |
| Unstressed **-er** | [ɐ] | Vater, aber, Computer, Lehrer |
| Prefixes er-, ver-, zer- | vocalised | verstehen [fɛɐ̯ˈʃteːən] |

> **Australian advantage:** Australian English is non-rhotic: you already drop the *r* in *father* and *butter*. The German *-er* in *Vater* ≈ the Australian ending of *father*, just slightly more open.
> **French advantage:** your French *r* works for the consonantal German r.
> In Switzerland and Austria you will also hear a tongue-tip (rolled or tapped) r. Both are correct Standard German.

### 4.3 Final devoicing (*Auslautverhärtung*)

At the **end of a word or syllable**, voiced consonants become voiceless:

| Written | Pronounced | Examples |
|---|---|---|
| b | [p] | gelb, ab |
| d | [t] | Hund [hʊnt], und [ʊnt], Abend [ˈaːbn̩t], Deutschland |
| g | [k] | Tag [taːk], Zug |
| s | [s] | Haus, Glas |
| v | [f] | aktiv |

When an ending with a vowel is added, the consonant starts a new syllable and becomes voiced again: *Tag* [taːk] → *Ta-ge* [ˈtaːɡə]; *Hund* [hʊnt] → *Hun-de* [ˈhʊndə].

## 5. Word stress and rhythm

| Rule | Examples |
|---|---|
| Native German words: stress the **first syllable** | **Na**me, **Mor**gen, **A**bend, **dan**ke, **woh**nen |
| Unstressed prefixes **be-, ge-, er-, ver-, zer-, ent-, emp-** | ver**ste**hen, Ent**schul**digung, Ge**spräch** |
| Many loanwords stress a **later** syllable | Stu**dent**, Phy**sik**, Universi**tät**, Mathema**tik**, Informa**tion**, Aus**tra**lien |
| Compounds: stress the **first part** | **Quan**tenmechanik, E**lek**trotechnik, **Haupt**bahnhof |

### The glottal stop: no French-style linking
Every word (and word stem) that begins with a vowel starts with a small "catch" in the throat [ʔ], like the break in English *uh-oh*. German **does not link** words as French does (no *liaison*/*enchaînement*):

*Ich arbeite am Abend* → [ʔɪç ʔaʁbaɪ̯tə ʔam ʔaːbn̩t]: four separate vowel onsets.

## 6. Spelling conventions

1. **All nouns are capitalised**, wherever they appear: *der Tag, die Physik, das Haus*. This helps you spot nouns in a sentence.
   - *der **M**orgen* (the morning, noun) vs. *bis **m**orgen* (until tomorrow, adverb)
2. **Formal *Sie*** (you) and its forms (*Ihnen, Ihr*) are always capitalised. Lowercase *sie* means *she* or *they*.
3. ***ich*** (I) is **not** capitalised unless it starts a sentence (unlike English *I*).
4. **ß vs. ss** (spelling rules since the 1996 reform):
   - **ß** after a **long vowel or diphthong**: Straße, heißen, groß, Fuß
   - **ss** after a **short vowel**: Wasser, dass, muss, Kuss
   - So ß/ss also tells you the vowel length.
   - There is a capital ẞ (official since 2017), but in all-caps text *SS* is still common.
5. 🇨🇭 **Switzerland and Liechtenstein do not use ß at all.** They always write *ss*: *Strasse, heissen, gross*. In Zurich you will see *Bahnhofstrasse*, not *Bahnhofstraße*. Both are correct in their own country.

## 7. Coming from French: what transfers and what doesn't

| ✅ Transfers well | ❌ Traps |
|---|---|
| German **ü** = French **u** (*tu*) | German **u** = French **ou** (*gut* ≈ "goute") |
| German **ö** = French **eu** (*deux*) | German **eu** = "oy" (*Deutsch*), not French *eu* |
| German **r** ≈ French **r** | German **ei** = "eye", not French *ei* [ɛ] |
| German long **e/o** ≈ French **é/eau** (pure vowels) | German **j** = English *y*, not French [ʒ] |
| | German **ch** is not French [ʃ] (except loanwords like *Chef*) |
| | **Final letters are pronounced**: *Hund* [hʊnt], *bitte* [ˈbɪtə] |
| | **No nasal vowels** in native words (*Mann* is not nasalised) |
| | **No liaison**: glottal stops instead |
| | **Stress usually comes first**, not last |

## 8. Common pronunciation mistakes

| Mistake | Correct | Code |
|---|---|---|
| *w* as English w: "wee" for *wie* | [viː] "vee" | PRON |
| Swapping **ei**/**ie**: *heißen* as "hee-sen" | "HYE-sen" [ˈhaɪ̯sn̩] | PRON |
| Gliding long e/o: *See* as "say", *so* as "sow" | Pure [eː], [oː] | PRON |
| *ch* as "k" or "sh": *ich* as "ick"/"ish" | [ɪç] | PRON |
| Forgetting final devoicing: *Tag* with a [g] | [taːk] | PRON |
| Silent final -e (French habit): *bitte* as "bit" | [ˈbɪtə] | PRON |
| *z* as English z: *Zürich* as "Zoo-rick" | [ˈtsyːʁɪç] "TSÜ-rich" | PRON |
| Pronouncing the lengthening h: *gehen* as "ge-hen" | [ˈɡeːən] | PRON |
| *sp/st* at the start as English: *Student* as "stoo-dent" | [ʃtuˈdɛnt] "shtoo-DENT" | PRON |
| *u* instead of *ü*: *für* as "fuhr" | [fyːɐ̯] | PRON |

## 10. Summary and revision notes

- German spelling is **highly regular**: learn the rules once and you can read aloud almost anything.
- **Vowel length** is predictable: double vowel / vowel + h / ie / single consonant → long; double consonant / ck / tz → short.
- **Umlauts** are separate vowels: ü = rounded "ee", ö = rounded "eh".
- **ei** = "eye", **ie** = "ee" (say the English name of the 2nd letter).
- **w** = v, **v** = f, **z** = ts, **j** = y, **sp/st** at the start = shp/sht.
- **ch**: ach-sound after a/o/u/au, ich-sound elsewhere.
- **Final devoicing**: b/d/g → p/t/k at the end of a syllable.
- **Stress** is usually on the first syllable, except unstressed prefixes and many loanwords.
- **Nouns are capitalised**; formal *Sie* is capitalised; *ich* is not.
- **Switzerland writes ss instead of ß.**
