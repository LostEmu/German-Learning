# Mistakes Log

Every mistake made in exercises and assessments, with an explanation and the correct form. This is the main input for re-teaching and for designing revision.

**How to use it:** before each cumulative assessment, re-read every entry marked *Open*. An entry is *Resolved* when the same structure is later used correctly in free production.

**Error codes:** see [assessments/README.md §5](../assessments/README.md#5-error-categories-used-in-progressmistakes-logmd) (PRON, SPELL, VERB, WO, CASE, GEN, REG, VOC, PREP, IDIOM).
